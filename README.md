================================================================================
             ART_RAG APPLICATION OVERVIEW & FEATURES
================================================================================

The Art_RAG application is a fully local, intelligent, and interactive assistant 
designed for art history research, image analysis, and cultural document 
management.

Here is everything you can accomplish with this application:

1. ANALYZE AND EXPLORE ARTWORKS (MULTIMODAL VISION)
--------------------------------------------------------------------------------
- Import artwork images (paintings, sculptures, drawings, photographs).
- Obtain automatic visual and stylistic analysis: identification of art 
  movements, composition techniques, color palettes, and key subject matter.
- Automatically generate descriptive keywords (tags) to categorize and easily 
  browse your private artwork collection.

2. BUILD A KNOWLEDGE BASE & LIBRARY
--------------------------------------------------------------------------------
- Load text files, research articles, or books in PDF, TXT, or Markdown formats.
- Organize your documents by topic (e.g., art history periods, artists, techniques).
- Automatically index document contents to make them instantly searchable.

3. ASK QUESTIONS AND CHAT WITH YOUR DOCUMENTS (RAG MODE)
--------------------------------------------------------------------------------
- Query the artificial intelligence directly about the contents of your loaded 
  documents (e.g., "What are the main characteristics of Picasso's Blue Period?").
- Receive precise, contextual answers backed directly by your personal source 
  materials and files.
- If information is missing from your local documents, the app can automatically 
  enrich its answers with Web and Wikipedia search results.

4. ACCESSIBLE VIA DUAL INTERFACES
--------------------------------------------------------------------------------
- Graphical User Interface (GUI): A modern visual layout featuring a chat panel, 
  drag-and-drop file upload zone, and artwork gallery.
- Command Line Interface (CLI): Quickly run automated tasks, rapid image 
  analyses, or document searches directly from the terminal.

5. 100% LOCAL PRIVACY AND PERFORMANCE
--------------------------------------------------------------------------------
- Complete data privacy: no data is sent to cloud servers—all analyses, images, 
  and text processing stay strictly on your local machine.
- Real-time hardware and memory monitoring to ensure smooth performance 
  and fast response times.
